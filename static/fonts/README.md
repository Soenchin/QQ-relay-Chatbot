The complete official WOFF2 is served locally via `/static/fonts/`; there is no runtime CDN or `local()` font lookup. This gives visitors the same version even when their computer has no Source Han Sans installed. `font-display: swap` keeps text readable during the first download; subsequent loads can use the browser cache. The full character set is retained for arbitrary chat messages and knowledge files, rather than subsetting only the current UI labels.
